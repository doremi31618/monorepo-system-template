# Release 0.2.1

> **Release date**: 2026-09-08
> **Status**: Approved for main integration

## Features

- **SUI-001 — Notion-like Data View Filter Builder**
  - Adds one reusable typed contract for search, filter, sort, pagination-ready relation options, and consumer actions.
  - Commits structured filters only after Confirm while keeping incomplete drafts local.
  - Supports text, enum, relation, number, date, and boolean editors.
  - Uses Popover on desktop and an accessible bottom Drawer on narrow screens.
  - Lets persistent search consume the available toolbar width while adjacent actions remain content-sized.
