# Release 0.2.0

> **Release date**: 2026-09-01
> **Status**: Released

## Features

- **CAP-001 — Capability Package Architecture**
  - Reorganizes workspaces by framework, capability, runtime, and framework-neutral types, with executable dependency-boundary checks.
  - Moves PostgreSQL migration ownership into the API composition root while keeping migration execution separate from API startup.
  - Adds the shared Svelte UI catalog, resizable/collapsible navigation, collapsible article settings, semantic light/dark tokens, and reusable admin data-view controls.
  - Pins Tiptap to `3.30.5` and fixes editor Enter, block-toolbar hover, blank-canvas insertion, and settings overflow behavior.
  - Integrates OAuth, Remote MCP, Task Runtime, and Service UI into the new package hierarchy.
  - Routes MCP and OAuth environment configuration through the API `ConfigModule`; these modules no longer read `process.env` directly.

- **MCP-001 — Remote MCP Server**
  - Adds standard Streamable HTTP endpoints at `/mcp/public` and `/mcp/private`.
  - Exposes read-only CMS search tools while reusing the same Nest CMS service used by REST APIs.
  - Protects private tools with OAuth resource audiences and existing RBAC permissions.
  - Adds the generic `@platform/nest-infra-mcp-server` adapter without coupling it to CMS.
  - Splits framework-neutral CMS contracts into `@platform/types-content` and NestJS implementation into `@platform/nest-content-cms`.
  - Adds package dependency checks, package README files, and Remote MCP onboarding guidance.

## Migration

- NestJS consumers must import `CmsModule`, `CmsService`, controllers, and schema from `@platform/nest-content-cms` instead of `@platform/types-content`.
- Framework-neutral CMS query/result types remain available from `@platform/types-content`.
- Deployments enabling the private endpoint must configure the documented MCP OAuth resource and JWT verification environment variables.

## Known risks

- Live OpenAI, ChatGPT development-mode, and Claude Code smoke tests require a public HTTPS deployment and suitable vendor account access. They were not executed in the local worktree; exact steps are documented in `doc/onboarding/how-to-add-remote-mcp-tool.md`.
- GitHub Actions reports that `actions/checkout@v4` targets deprecated Node.js 20 and is currently forced onto Node.js 24. This is a maintenance warning, not a failed release check.

## Rollback

- Revert the `dev -> main` release merge commit.
- Restore API imports from `@platform/nest-content-cms` to the previous CMS package only together with the corresponding package/schema changes; do not partially roll back the package split.
- Remove or disable MCP route composition from `apps/api/src/mcp` if an endpoint-level emergency rollback is required.
